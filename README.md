# 地方非遗文化数字化保护数据库管理系统

《数据库原理》课程设计项目。以 MySQL / MariaDB 为核心，完成非遗档案、传承人、作品、研学活动与报名业务建模，并通过 Flask REST API 与原生前端页面提供可视化演示。

## 项目规模

- 11 张业务表、7 个视图、6 个触发器、6 个存储过程、4 个自定义函数、1 个定时事件
- 42 个索引（11 主键 / 13 唯一 / 18 普通）、18 个 CHECK 约束、12 个外键、248 个字段
- 22 个 REST 接口、4 个前端页面、离线快照降级模式
- 核心算法：非遗活态传承热度指数 HVI、研学活动混合推荐（SQL 与服务层双实现）

## 目录结构

```text
01_数据库脚本/   建表、初始数据、视图、函数与存储过程、触发器、核心查询（按 01~06 顺序执行）
02_课程设计报告/ Word 课程设计报告（12 章 + 附录）
03_后端服务/     Flask 应用、数据访问层、算法层、配置与依赖清单
04_设计图表/     ER 图、物理结构图、运行截图
05_前端页面/     数据看板、非遗档案、研学活动、数据库能力演示
tools/           报告生成、ER 图生成、快照导出、数据库统计与校验脚本
项目介绍.html     面向非技术读者的自包含介绍页
选题创新改进方案.md  新颖性提升方案（设计文档，尚未实现）
```

## 快速开始

### 1. 准备数据库

安装 MySQL 8.0 或 MariaDB 11.4+，按顺序执行：

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p < 01_数据库脚本/01_schema.sql
mysql -h 127.0.0.1 -P 3306 -u root -p < 01_数据库脚本/02_init_data.sql
mysql -h 127.0.0.1 -P 3306 -u root -p < 01_数据库脚本/03_views.sql
mysql -h 127.0.0.1 -P 3306 -u root -p < 01_数据库脚本/04_functions_procedures.sql
mysql -h 127.0.0.1 -P 3306 -u root -p < 01_数据库脚本/05_triggers.sql
mysql -h 127.0.0.1 -P 3306 -u root -p < 01_数据库脚本/06_core_queries.sql
```

原课设环境使用端口 `3399`、用户 `root`、空密码。可通过环境变量覆盖：`HERITAGE_DB_HOST`、`HERITAGE_DB_PORT`、`HERITAGE_DB_USER`、`HERITAGE_DB_PASSWORD`、`HERITAGE_DB_NAME`。

> 注意：`05_triggers.sql` 中包含报名触发器的验证用例，部分演示活动使用了固定日期。若当前时间晚于其报名截止时间，验证用 INSERT 会按触发器规则报错，属于预期约束行为。

### 2. 启动后端

```bash
pip install -r 03_后端服务/requirements.txt
python 03_后端服务/app.py
```

访问 `http://127.0.0.1:5000/`。接口清单见 `03_后端服务/README.md`。

### 3. 离线演示

后端未启动时，直接打开 `05_前端页面/` 下的任一 HTML，页面会自动切换至 `assets/js/snapshot.js` 中的离线快照；`项目介绍.html` 为完全自包含的单文件介绍页，不依赖网络。

## 数据与隐私说明

- 所有项目、传承人、学生与活动数据均为课程设计用的虚构演示数据。
- 数据库连接使用本地空密码 root 账户，仅适用于本机开发演示；部署到公网前请务必创建专用账号与强密码。
- 前端无外部 CDN 依赖，所有样式、脚本、图表均为本地文件。

## 唯一缺口：HNSW 未实测

降级模式下 `<=>` 运算符与 HNSW 索引都不存在，因此：

- 不把 GAP 改写成 PASS；
- 需要「必须实测」的场景改用 `--require-hnsw`，此时该条判 **FAIL** 且进程退出码为 1，
  避免缺口被忽略；
- `scripts/bench_pg.py` 的 `vector_knn` 场景如实标为 **SKIPPED**，
  不拿精确扫描的耗时冒充向量检索性能。

要真正消掉这条缺口，需要一台能起 pgvector 的机器：

```bash
docker compose up -d                       # pgvector/pgvector:pg16
python scripts/init_db.py
python -m tests.check_pg --require-hnsw    # 应转为 PASS
python -m scripts.bench_pg                 # vector_knn 应转为 OK
```

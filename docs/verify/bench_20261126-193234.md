# 性能采集 20261126-193234

- 数据库：`ich_heritage`（PostgreSQL 16.15）
- 向量模式：pgvector 原生（HNSW）
- 环境：`PostgreSQL 16.15, compiled by Visual C++ build 1944, 64-bit`
- 规模对照：`vector_knn_syn*` 的合成数据在事务内生成，脚本结束时整笔回滚，**未落库**；固定随机种子可复现

> 默认设置为优化器自由选择；「关闭索引」组为 `enable_indexscan=off, enable_bitmapscan=off`，用于判断索引是否可用，不代表线上实际计划。

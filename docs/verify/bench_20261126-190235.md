# 性能采集 20261126-190235

- 数据库：`heritage`（PostgreSQL 16.2）
- 向量模式：降级（NUMERIC[] + 精确扫描）
- 环境：`PostgreSQL 16.2, compiled by Visual C++ build 1937, 64-bit`

> 默认设置为优化器自由选择；「关闭索引」组为 `enable_indexscan=off, enable_bitmapscan=off`，用于判断索引是否可用，不代表线上实际计划。

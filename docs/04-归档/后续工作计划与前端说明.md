## 二、前端：页面、组件、交互（可直接运行）

### 2.1 它现在是什么样

`app/static/index.html`（615 行）+ `app/static/app.js`（约 980 行），原生 JS，**无构建步骤、无 node_modules、无 CDN 依赖**——双击 svg 图标都没有，样式全在 `index.html` 的 `<style>` 里。这是刻意的：答辩现场最怕"npm install 卡住"或"学校网络连不上 CDN"。

### 2.2 四个页签（按角色显隐）

| 页签 | `data-page` | 谁能看到 | 依赖接口 |
|---|---|---|---|
| 作品上传 | `upload` | 传承人 / 管理员 | `POST /api/asset/upload`、`POST /api/asset/{id}/analyze` |
| 我的作品 | `mine` | **仅传承人** | `GET /api/asset/mine`、`/trace`、`/licenses` |
| 专家工作台 | `workbench` | 专家 / 管理员 | `GET /api/audit/pending`、`GET /api/asset/{id}`、`POST /api/audit/{id}/approve`、`/reject` |
| 监管台账 | `ledger` | 管理员 | `GET /api/ledger`、`GET /api/asset/{id}/trace` |

显隐逻辑在 `app.js:178-184`：传承人登录后默认落在 `upload`，专家/管理员默认落在 `workbench`。

**全局**

**④ 监管台账** — `#ledgerStats` 三张统计卡、`#ledgerFilter` 级别筛选（全部/公有/衍生/原创）、`#ledgerBody` 台账表（含 AI 与专家一致列）、`#traceModal` 溯源时间轴：
- 顶部链路校验结论（`✓ 链路完整，共 N 个事件节点` / `⚠ 发现 N 处问题`）
- 每个节点：序号圆点、事件摘要、类型徽章、时间、操作者与角色、状态与意见、可展开的 JSON 数据快照

### 2.4 交互细节（这些是差异化，不是必须）

- 全部列表渲染走 `esc()` 转义，标题里的 `<script>` 不会被执行
- 401 自动登出并跳到登录页；403 保持会话只提示
- 422 校验错误被拼成中文可读文本（`字段: 原因；字段: 原因`）
- 数值单元格统一走模块级 `nz(v, fallback)`，不会出现 `undefined 件`
- 单文件 20MB / MIME 白名单后端校验，前端先做一次预检

### 不建议做的

- **不要换前端框架**（React/Vue）。当前原生 JS 是"零构建、断网可用"的优势，换成框架就要 npm，答辩现场风险反增。
- **不要为了"看起来 AI"而加 LLM 描述生成**。本项目的 AI 职责是"向量相似度 → 分级建议"，加 LLM 会让"AI 只写建议"的边界变模糊，反而削弱论证。

## 四、本轮修掉的两个前端缺陷（已回归测试）

| 缺陷 | 现象 | 根因 | 修法 |
|---|---|---|---|
| 演示模式漏返回 `version_no` | 「我的作品」版本列显示 **`vundefined`** | `demo.list_my_assets()` 只返回 8 列，`services.list_my_assets()` 的 SQL 查 9 列。切库前看不出来，切换时才炸 | `app/demo.py` 补齐 9 列并加注释说明"必须与真实实现逐列一致"；`app.js` 版本列加 `nz()` 兜底 |
| 传承人打开授权弹窗出现 403 | 浏览器 console 一条红色 403 | `openLicense()` 无条件请求 `/api/users`（限 expert+admin） | 按角色判断，传承人跳过该请求 |

同时把 `nz()` 从两个函数内的局部定义提升为**模块级唯一实现**——原来两处 `const nz = (v) => ...` 会遮蔽新加的带 fallback 版本。

**新增 2 条不变量测试**（`tests/test_invariants.py`，64 → 66 项）：

```
✓ nz() 为模块级唯一实现
✓ 我的作品：演示模式覆盖真实库的全部列
✓ 我的作品：前端引用的字段后端都有返回
```

第二、三条用正则从 `services.py` 的 SELECT 子句抽出列名，与 `demo.py` 返回的字典键做集合比对，再与 `app.js` 里 `a.xxx` 的引用做比对。这类"两套实现字段漂移"的 bug 以后再出现会被测试挡住。

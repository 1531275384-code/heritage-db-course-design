# 演示前端与示例数据说明

## 可选演示方式

1. 交互式服务：根据仓库根目录 `README.md` 启动应用，使用示例账号完成上传、分析、审核、台账和溯源演示。
2. 静态演示页：直接打开 `output/01-交付物/演示页面.html`，无需启动数据库服务。
3. 互动演示页：打开 `output/01-交付物/演示页面_互动版.html`，按页面提示体验角色与流程切换。

## 数据说明

示例数据由 `data/seed_demo.json` 提供，包含示例用户、传统母题、资产、审核流水和授权记录。图片文件位于 `data/` 对应子目录。示例环境用于课程演示；真实数据库运行与权限、事务、向量检索验证结果见[课程设计主报告](课程设计主报告.md)及 `docs/verify/`。

## 测试基线

当前完整自动化测试为 **15 套 / 641 项断言 / 0 失败**。数据库专项结果包括 PostgreSQL 验收 50 项、并发验收 30 项、规则对拍 79 项和备份恢复 37 项。

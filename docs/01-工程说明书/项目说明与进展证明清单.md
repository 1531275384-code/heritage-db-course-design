# 项目说明与验证入口

本课程设计的唯一权威技术报告为[《非遗数字资产分级确权与溯源系统——数据库原理课程设计主报告》](课程设计主报告.md)。报告集中说明业务背景、关系模式、规范化设计、权限与触发器、索引、视图、并发控制、性能实测、备份恢复和自动化验收。

## 快速复核

- 数据库结构：`sql/01_init.sql`、`sql/02_index_trigger_view.sql`。
- 真库、HNSW 与性能记录：`../verify/验收记录-20261126.md`、`../verify/bench_20261126-193234.md`。
- 物理存储：`../verify/物理存储与TOAST实测-20261126.md`。
- 并发验收：`../verify/concurrency_20261126.log`，30 项通过。
- 备份恢复：`../verify/备份恢复演练-20261126.md`，37 项通过。
- 全量测试：在配置 PostgreSQL DSN 后运行 `python tests/run_all.py --all`，当前基线 15 套 / 641 项 / 0 失败。
